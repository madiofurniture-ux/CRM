# Dependencies & Infra — MADIO CRM

## Hosting
- **Backend**: Render (`render.yaml`), free web service, `rootDir: backend`,
  `uvicorn server:app`. Secrets (`MONGO_URL`, `CORS_ORIGINS`) set in the Render
  dashboard, not committed. `JWT_SECRET` auto-generated by Render.
- **Frontend**: Netlify (`netlify.toml`), builds `frontend/` with CRA
  (`npm run build`), `CI=false` so lint warnings don't fail the build.
  `/api/*` is proxied to the Render backend (same-origin from the browser, so
  the backend needs no CORS config for normal use). SPA fallback serves
  `index.html` for all other paths.
- **Netlify edge function**: `netlify/edge-functions/auth.js`.
- Legacy artifact: `MADIO_CRM_v16.html` / root `index.html` — an older
  single-file standalone app. `netlify.toml` explicitly documents that it
  *used to* be what got deployed and has since been replaced by the
  frontend/ build; don't resurrect the old redirect rule.

## External services
- **MongoDB Atlas** — primary datastore, connected via `MONGO_URL`.
- No S3/Stripe/email integration wired up despite `boto3` and
  `requests-oauthlib` appearing in `backend/requirements.txt` — grepping
  `backend/*.py` found no actual usage. Likely leftover from a template;
  don't assume file storage or OAuth exists.
- Attendance check-in reads camera + geolocation client-side (see
  `Permissions-Policy` in `netlify.toml`) — no third-party geo/vision API,
  it's browser APIs.

## Backend library stack (`backend/requirements.txt`)
FastAPI, uvicorn, motor + pymongo (Mongo driver), pydantic v2, pyjwt +
passlib + bcrypt (auth), python-jose (present, auth.py primarily uses pyjwt —
check before assuming both are load-bearing), pandas/numpy (used in
reports/analytics routes), typer (present, no CLI entrypoint found in
backend/ — check `backend/tools/` before relying on it).

## Frontend library stack (`frontend/package.json`)
React 19, react-router-dom v7, craco (build tooling over CRA), Radix UI
primitives + shadcn/ui conventions, Tailwind + tailwind-merge +
tailwindcss-animate, axios, recharts, react-hook-form + zod + @hookform/resolvers,
sonner (toasts), cmdk, vaul, embla-carousel-react, lucide-react (icons),
next-themes (light/dark), input-otp.
