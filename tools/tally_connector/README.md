# MADIO Tally Connector

Keeps the MADIO CRM refreshed from Tally. Runs on the office computer that
runs Tally, reads Tally's XML server on localhost, and posts to the CRM.
Read-only towards Tally; standard-library Python only.

Setup and details: [docs/TALLY_CONNECTOR.md](../../docs/TALLY_CONNECTOR.md).
